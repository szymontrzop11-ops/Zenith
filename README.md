# Zenith Discord Bot

A Discord moderation bot with ticket system, automod, and more!

## Features

- Moderation commands (ban, kick, mute, unmute, purge, etc.)
- Ticket system with support roles
- Automod for curse word detection
- Welcome messages
- Rules embed
- Logging system

## Setup

1. Create a `.env` file with all your configuration
2. Run `npm install` to install dependencies
3. Run `npm run deploy` to register slash commands
4. Run `npm start` to start the bot
